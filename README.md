# PitForge
SEO-first CMS for one-page landing sites — brand it, build it, and export a static site ready to deploy on any domain.

PitForge is a content management system for producing one-page landing sites at volume. Configure a brand — logo, palette, typography, copy — and PitForge assembles a complete site with structured data, meta tags, sitemap, robots.txt, canonical URLs, and Core Web Vitals handled by default. Every project exports as a self-contained static bundle you can drop onto any server, behind any domain, with no runtime dependency on PitForge itself.

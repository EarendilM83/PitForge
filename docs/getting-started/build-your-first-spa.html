Before you start

Two tools, working together

PitForge is not one app — it is a build engine and an editing studio. Knowing which does what makes everything else obvious.

Claude Code — the builder

Turns designs & words into the site

  • Converts a Figma design into a real project
  • Makes structural / design edits you ask for in plain language
  • Runs the responsive + SEO gates before calling anything done
  • Produces the deployable export bundle
PitForge Studio — the editor

Where you see and tweak the site

  • Lists your sites; opens each in a live editor
  • Click any text or image to change the words / picture
  • Set the SEO — title, slug, meta, Google preview
  • Preview at every screen size, then export a ZIP

Set up — one time only

Developer

A developer does this once per machine. Marketers skip straight to step 1.

  • Clone the PitForge repo and install dependencies
  • Install Claude Code and sign in with your subscription
  • The safety fence ships in the repo — Claude can edit sites but never PitForge itself, and never deploys
# in the PitForge folder npm install npm i -g @anthropic-ai/claude-code claude # sign in on first run
📄 Full setup, the safety fence, and the boundary smoke-test live in CLAUDE-SETUP.md at the repo root.
1

Start the Studio

Marketer

Run the dev server and open the Studio. First time in, a short “How it works” tour walks the same journey you’re reading now — you can reopen it anytime from the Sites screen.

npm run dev # opens the Studio at localhost:4321
  • Keep this running while you work
  • The Sites screen lists every landing page in the project
2

Create your first site

Marketer

Click + New site. Choose Import from Figma — paste your Figma design link — or start blank. The dialog writes a ready-to-run prompt for Claude Code.

  • Import from Figma → paste the design URL
  • Give the site a name and a URL slug (e.g. /summer-bonus)
  • Copy the generated prompt into Claude Code
💡 A Figma link is the fast path — Claude reads the real design (colours, spacing, fonts) instead of guessing from a picture.
3

Claude builds it

Claude Code

Paste the prompt into Claude Code. It maps the design, scaffolds the project (one block per section), and writes the content — then proves it’s done by running both gates. It won’t hand back a broken page.

✅ Responsive gate — renders 320→2200px, fails on any real break.
✅ SEO gate — one <h1>, correct heading order, meta, structured data. A fail blocks export.
🔄 A brand-new site needs one dev-server restart to appear in the Studio — Claude will tell you.
4

Open the editor

Marketer

Back on the Sites screen, click Edit. The left Elements panel lists every section and the fields inside it; the canvas shows the live page.

  • Sections group the fields — Hero, Bonus, Games, FAQ, Footer…
  • Click a field name to jump to it on the page
  • The 🔒 Marketer mode keeps structure safe — you edit content, not layout
5

Edit the content — just click it

Marketer

Click any headline, paragraph, button, or image — right on the page or in the panel — and change it. The edit shows instantly. A live search-engine check confirms the heading is still valid as you type.

  • Text: type over it; a counter warns if you exceed the limit
  • Images: upload a new file, set the alt text
  • “What kind of element is this?” changes only its meaning for Google & screen readers — never the look
✨ Need a sharper line? The optional AI copy buttons can improve, shorten, or translate the selected text — but plain typing works the same.
6

Set your SEO

Marketer

Open the Page tab. Edit exactly what Google shows — the page title, the URL slug, and the meta description — with a live Google preview so there are no surprises.

  • Title & description can auto-follow your page content, or be set custom
  • Slug: lowercase, dashes — the page’s web address
  • These feed the SEO gate that guards every export
7

Preview the real site

Marketer

Hit Preview to see the actual rendered page — the same zero-JS HTML that ships. Check it at phone, tablet, and desktop widths using the size toggles.

  • This is the truth — what a visitor will load
  • If a width looks off, ask Claude to fix it the fluid way (no fixed-px patches)
👀 The preview is always live; an exported ZIP is a frozen snapshot. Re-export after changes.
8

Export the bundle

Marketer

Click Export, enter the live domain, and Download ZIP. The SEO checks run one last time — if anything fails, the export is blocked until it’s clean, so you can’t ship a broken page.

  • The ZIP is a complete, self-contained static site
  • Claude can also produce it from the terminal — same gated result
npm run export -- --project <slug> --domain https://yoursite.com
9

Deploy — hand it off

Owner

The last step is deliberately human. Give the exported bundle to the site owner — they upload it to the GitLab repo, and the pipeline ships it to Cloudflare Pages instantly.

  • Claude never deploys and holds no credentials — it stops at the ZIP
  • The owner owns the deploy: upload → pipeline → live
🚀 That’s it — your first SPA is live on Cloudflare Pages.
